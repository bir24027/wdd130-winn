Top Nutation

Description

This project was the cumulation of everything I learned about programming with functions. I wrote a program that uses several functions I created to visualize the rotation of a top and find an angular frequency at which the top can rotate with a constant vertical angle (theta). To do this, it first calculates the potential energy (a function of theta) for a range of theta values. Then it creates a graph of the potential energy vs theta. After that the program finds the minimum potential energy and the theta value corresponding with that. The program then takes that theta value and uses it to calculate the approximate and exact angular frequencies for that constant theta value.

Explanation

Nutation is a swaying or nodding motion in the rotation axis of an object that is mostly symmetrical about that axis. Think of the tilt in the earth’s axis. The precession rate of an object is how its nutation changes over time. This program focuses on the nutation of a top, which is controlled by its effective potential energy. The main function of this program calls all the other functions within the program to calculate the vertical angle and the potential energy, graph the potential energy vs. the vertical angle, find the angle associated with the minimum potential energy, and finally calculate the approximate and exact precession rates.

Advanced Projectile Motion Simulation

Description

For this project, I wrote a C# program that uses classes and inheritance to calculate the trajectory of a custom projectile. It includes a text menu that allows the user to enter custom parameters for the projectile and environment as well as choose what factors should be factored into calculating the trajectory. Those factors include adiabatic density, wind, magnus force, and viscous collision. Once they are chosen, the program uses the associated class or classes to calculate the trajectory and display a set of x and y coordinates to the user.

Explanation

When any object is shot or thrown in an environment with gravity, it experiences projectile motion and has a parabolic trajectory that can be calculated. In this particular program, I used a 4th order Runge-Kutta technique, which uses the acceleration in each direction to predict the change in velocity and the velocity to predict the change in position. The program itself contains a class for each factor that inherits functions using the Runge-Kutta technique from the Trajectory class. There is also a custom class for any combination of two or more factors and a custom class for all the factors. Each class has additional functions or overrides the original functions when needed to customize the calculations for the situation.

To-Do List Web Application

Description

This project was a collaboration between me and three other students to create a to-do list application with user authentication. The first page a user encounters is the login page, where the user can enter their credentials, the backend will check them against the username and password stored in the database, and the user moves on to the list page. There is a register button as well that takes the user to a page where they can create a username and password and an entry can be created in the database. The list page displays all the tasks that have been created with a name and a description, which are also stored in the database. New tasks can be added at the bottom and specific tasks can be searched for at the top.

Explanation

This web application consists of the frontend and the backend. The frontend contains four HTML page templates that determine the structure of each page of the website, the images, and the CSS file that determines the styling of the pages. The backend consists of two python files, the server, and the MySQL database. The app file uses Python Flask to render the pages, and the api file communicates between the frontend and the server. When a request is made on the frontend (a button is pushed, a page is loaded, etc.), the api communicates the request to the server, which gets the information from the database and gives it to the api, then finally the api gives the information to the frontend so it can be displayed.
